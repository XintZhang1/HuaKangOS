# huakangos · 华慷集团

本轮简化销售、售后、库管和财务的常见操作：车型一张表录入、预订合同直接建单、资料实时搜索、表内补建和上传、减少重复填写。具体变化和剩余问题见[员工操作简化](docs/员工操作简化_20260924.md)。业务助手保留现有DeepSeek配置。

本机入口：[打开 huakangos](http://127.0.0.1:8000/)。使用已设置的管理员账号；试用说明见[业务助手使用说明](docs/业务助手使用说明.md)，完整手工流程见[从零试用操作手册](docs/从零试用操作手册.html)。按需求表逐组试用见[XC 试用运转说明](docs/试用运转说明-XC.md)；这个目录如果还没建过预览库，启动后先按页面提示设置管理员密码。

应用仍为 `0.4.0-dev`。本轮候选数据库头为 `f24s_business_assistant`，月结定义21、现金定义7保持。真实模型和浏览器结果、全量回归、原资料保护与未验证内容见[验收与限制](docs/验收与限制.md)；不继承旧版本成绩。

193项原需求按逐项适用范围保留，见[需求验收台账](docs/需求验收台账.md)。会员中心仅做记账；集团实际资金清算及门店合作准入审批继续排除。公司实际业务验收及正式启用仍未完成。

## 首次试用

同一目录再次双击 `start-preview.cmd` 会复用已运行的实例，账号和资料保留；预览库按源码目录路径绑定，换了目录或新电脑会先要求设置一次管理员密码。以下为初始化说明。

新安装需要 Python 3.11—3.13。Windows 推荐双击 `start-preview.cmd`，首次在页面设置自己的管理员密码。资料位于源码之外；完整说明见 [本机预览启动](docs/本机预览启动与首次设置.md)。

如需带虚构业务的演示库，Windows 在独立目录打开终端：

```powershell
$env:FILE_SCAN_MODE = 'structure_only' # 仅本地虚构试用，未查毒
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Demo
```

macOS / Linux：

```bash
FILE_SCAN_MODE=structure_only bash start.sh --demo
```

首次初始化会要求设置至少12位管理员密码，没有默认密码。打开 `http://127.0.0.1:8000`，账号 `admin`。后续启动去掉 `-Demo` / `--demo`。初次安装依赖需要网络；业务页面运行不需要 Node.js 或外部图表服务。

演示库有两家虚构门店、不同岗位及不同进度的业务。演示员工账号使用不可预知的随机密码，管理员在“员工账号”中重置后才能试用，首次登录必须改密。没有共用默认员工密码。

## 这版有什么

原有15类流程业务：接待、车辆订单、维修、精品加装、保险、代办、物资采购、领料、退料、盘点、回访、投诉、会员充值、会员退款、开票登记。部分只能由上游业务产生，避免重复录入。

9个可视化视图、基础经营图表及集团会员往来图表、按同批接待定义的转化分析、当前库存和待收款、岗位待办量、明细钻取、中文CSV导出。只使用标准折线和柱形图，不把收入、到账和余额混算。

5种可编辑文字模板，生成DOCX、模板版本及数据快照、上传原始凭据、合同和提车签回件关联。默认模板未启用，先由公司确认。样例文件不用于真实签约。

多门店后端隔离、员工角色、任务转交、重复请求保护、版本冲突保护、不可直接修改的收款/库存/储值流水、数据库一致性备份。已支持同一账号在不同门店担任不同岗位；集团汇总需要单独授权，且不提供办理权限。集团本金、赠金、积分、券和套餐独立记账，内部往来独立于实际现金；原门店储值不自动合并。

自动改代码、Git推送、飞书代码审批、自动覆盖发布已移除。日报保留程序汇总和可选外部模型摘要，默认不开启外发，不参与业务流转。

## 不要直接部署公网

默认只监听本机。正式多人使用前，需要HTTPS、最小权限、公司模板确认、备份恢复演练和业务验收。SQLite用于这一轮试用；并发和容量上限未经真实门店压测。Docker/PostgreSQL示例不是已完成的生产验证。
