# 搜索、图文指引与业务助手

登录后，在页顶的“搜索功能或操作”直接输入要做的事。也可以按 **Ctrl+K**（Mac 为 **Cmd+K**）。例如输入“订车”“录车型”“客户怎么建”“退钱”“员工账号”，结果随输入出现，不需要再点查找。用鼠标选择，或用方向键和 Enter 打开；Esc 关闭。

**普通搜索**：默认使用这个模式，边输入边显示结果。即使没有匹配结果也不会调用 AI，无需等待模型回答。

**AI 搜索**：普通搜索没有找到时，点“试试 AI 搜索”；也可以随时选择上方“AI 搜索”。点击时会按当前输入查找一次。进入 AI 模式后，改写内容不会自动调用；按 Enter 或点“AI 搜索”才再次查找。两个模式分开展示，点“普通搜索”立即回到关键词结果。相同账号、门店和查询在本次页面内复用成功推荐。

每条结果都可选 **进入页面** 或 **查看说明**；支持直接新建的业务另有 **新建售前接待、新建预订合同、新增车型** 等按钮，点击即打开原表单。共40个现有表单快捷入口，仍需填写、核对并提交。退款、退货等需先选原单的操作从对应业务页面开始。图文说明顶部也提供同样的页面及表单链接。

AI 只推荐现有入口和说明，不查客户资料或提交业务。换词、关闭、切回普通搜索或切店会取消当前等待，迟到回答不会混入新结果。失败后可手动再搜。离线 HTML 支持关键词搜索，AI 搜索从登录后的系统使用。

左栏“操作指引”可以浏览全部流程。原需求名称和 HK 编号也能搜索，例如 `HK-001`。

## 跟着一个流程试用

1. 选一家门店，搜索想办的业务，打开指引。
2. 看“开始前准备”，核对本次需要的资料。图片是演示入口，可点击放大；放大后可横向滚动查看细节。
3. **手动办理**：可从说明顶部直接进入页面或打开表单，再按步骤办理。每步都有经办岗位和完成后的结果。
4. **业务助手办理**：点“让助手带我办”，目标先填入新的对话草稿。核对后点发送，按助手问题补资料；表单填好后仍由你核对确认。仅打开指引或进入助手不会创建业务。
5. 遇到缺资料、没有原单或需其他岗位接手，查看“遇到问题”；完成后按“完成后核对”检查单据和结果。

系统设置以及必须在原页面办理的步骤，按钮叫“让助手帮我准备”。助手会整理资料和说明入口，不代替实际审批、付款、收货、签字或质检。

## 常见情况

| 情况 | 怎么办 |
|---|---|
| 找不到想做的事 | 换一个简短业务词，或输入原需求名称/编号；也可按业务分类浏览。 |
| 原页面有表单没填完 | 先保存或明确关闭原表，再从指引进入别的业务。 |
| 助手里还有没发出的内容 | 系统保留原内容。先发送或清空，再从指引开始新流程。 |
| 当前步骤由其他岗位办理 | 按步骤中的岗位交接；对方从自己的待办或原单继续。 |
| 切换了门店 | 重新查找本次要办的流程；尚未发送的助手草稿会清空。 |
| 想从 Excel/Word 等资料填表 | 在业务助手“资料整理”选择文件或文件夹，核对并选择内容后发送。具体限制见[本地资料手册](本地资料与业务助手试用_20260924.md)。 |

## 离线手册

双击 [全量工作流手册.html](全量工作流手册.html) 即可打开。111个典型流程、原193项需求映射和70张入口图片都包含在这一个文件中，约20MB，不依赖旁边的图片文件夹。

离线手册能搜索、看图、切换两种办理方式和打印当前流程。“复制给业务助手”会复制本流程目标，粘贴到系统助手后再发送；浏览器不允许复制时会显示可选中的文字。

离线版业务链接默认打开本机8000端口。部署服务器后，请在系统内“操作指引”打开业务，避免打开错误的环境。系统内图文手册使用当前站点，不依赖本机地址。

截图全部来自独立演示库，图片中的人员、客户和数据仅供识别入口。每张图片是实际页面入口，不代表本流程已经完成；按步骤使用本店实际资料办理。36项统计也分别有指引，期间、筛选和导出仍以实际报表为准。
