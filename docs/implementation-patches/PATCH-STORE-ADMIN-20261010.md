# 2026-10-10 总经理完整核价与门店管理员

## 追加授权与边界

业主明确总经理须在其已授权门店查看完整核价，包括此车销售总成本、此车销售利润、赠品成本和返佣。此授权覆盖旧版“总经理不自动获敏感权限”的限制；继续保持门店范围、人工核算、独立审批和已批准合同锁档。

保留系统管理员，新增独立 `store_admin` 门店管理员。最小范围为当前授权门店业务数据读取、查询、报表及来源导出、发票原件只读、本店业务审计，以及本店独占的普通员工账号维护。普通岗限销售、销售经理、销售内勤、收银；支持新增/批量新增、改普通岗位、启停、重置密码，必须复用锁、版本及会话撤销。不能管理自身、其它管理员、总经理、集团副总、董事长、跨店或获集团汇总的账号。

只更新既有 draft PR #17；不合并、不部署、不写生产数据，不添加删除能力。

## 实施安全边界

- `User`、`UserStore`、`Store` 为全局表，不依赖业务 ORM 的门店过滤保护账号操作。只返回当前店独占普通账号，写入事务内重验发起人和目标作用域；批量整批校验后创建。
- 新角色与现有 admin 分离；不得获得全局管理员旁路，不允许集团汇总、门店授权扩展或混配其它门店岗位。仅系统管理员分配门店管理员。
- `get_user` 对门店管理员增加显式路由/方法边界；未列入本店维护或读取范围的旧业务、全局配置、部署/运维和助手接口拒绝，不靠前端隐藏。
- 当前记录域、报表、搜索、统计、导出、附件均沿用门店 scope；业务写入、合同审批、核价录入、到账、发票确认、标准价导入、目标下达不授予门店管理员。
- 门店审计仅本店业务记录和安全投影的账号维护事件；不开放全局日志或完整跨店账号快照。
- 原系统管理员能力、历史账号和历史迁移保持；追加迁移。岗位显示、账号表单、批量入口、业务只读导航及助手入口随服务端能力返回。

允许修改相关身份/账号/租户/记录读取/审计模块及必要辅助、追加迁移、前端、定向测试和说明；不改旧迁移或 `total_plan.md`。
