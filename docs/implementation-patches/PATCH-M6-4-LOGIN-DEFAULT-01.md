# PATCH-M6-4-LOGIN-DEFAULT-01：登录后采用服务器默认首页

2026-09-30，本轮实际浏览器点击发现：无深链接登录被 loginPage 固定写成 #work，导致 bootDefaultRoute 无法读取服务器助手首页开关。

本补丁属于当前 M8.1 集成收口，精确范围仅 web/app.js 登录成功后的 route 初始化及计划/审阅记录。保留有效人工业务深链接；没有有效深链接时清空 hash，由既有 bootDefaultRoute 按服务器功能开关与岗位决定首页。四个生产默认开关不改变，隔离合成夹具才开启。无新权限、导航或持久化方式。

验证通过新原生浏览器点击脚本：无 hash 登录落助手首页、有效 #master/customers 深链接仍到人工客户页；服务器开关关闭行为继续沿用原 bootDefaultRoute。保留首次失败隔离快照与截图，不继承历史首页测试成绩。
