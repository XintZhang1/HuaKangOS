## 原失败与因果

外部 run `20261003T064631Z-7769222357` 的 `requirements-representative-forms` 在 `wf-employee-store-roles` 报“新增员工默认门店被勾选/漏掉可用门店”。初始化 manifest 只登记门店 1、2；此前原管理员 UI 已分别创建启用门店 3、4（审计 644、653，UTC 07:54:44、07:56:22），两场 Runtime 场景均通过。08:01:23 失败模态框列出四店并显示“尚未选择门店”，默认 sales 检查已通过。最终库的门店 5 是 08:03:09 后续创建，不能倒用为该时刻候选。

原 API `/api/users` 经过管理员守卫返回真实门店；原新员工 UI 只显示当前启用门店，默认 sales 且不预选门店。测试用初始化 manifest 数量核对动态候选，误报实际新增门店。旧失败证据及退出结果保留，不事后改写为通过。
