## 精确范围与原因

新增 `tests/assistant_offline/` 的定向回归源码和只读复制执行入口；更新 `.github/workflows/assistant-offline-checks.yml` 执行同一入口；在 `AGENTS.md` 追加当前测试授权，在运维说明中记录实际 worker 调度行为。不是恢复旧清理归档，也不是另建里程碑记录源。

此前源码与测试分开打包，无法仅凭 Git 提交复跑。本补丁将本轮测试**源码**版本化；生产源码打包脚本仍排除 tests。合成数据库、随机密码、配置、日志、浏览器截图及报告继续在仓库外的唯一新目录，不提交 runtime，也不读取用户 `.env` 或已存在实例。`run_isolated.py` 只用标准库验证、复制和启动外部执行器，应用导入在隔离环境确定后发生。

## 必须保留的失败与边界

- 拒绝已有输出目录、位于源码内部的输出目录、不完整源码及含 `.env` 的源码；不删除旧库/证据来重跑。
- 模拟 provider 仅返回显式序列，外部模型连接被拦截；原 ASGI/loopback 业务 API、权限、事务和数据库实际执行。
- 原生浏览器模式使用真实 HTTP、Cookie 和 SSE；fixture 模式使用显式桥接。原生失败即失败，不修改浏览器策略，不自动切换模式求绿。
- CI 仅有只读仓库权限；不读取 Secrets、不部署、不启用生产功能开关。只上传 evidence，不上传 runtime。
- 每项退出码、非零用例计数、源码/测试指纹与模式一并记录；不能把本定向套件记为原 101/283、193 需求或 M8 完整验收。
