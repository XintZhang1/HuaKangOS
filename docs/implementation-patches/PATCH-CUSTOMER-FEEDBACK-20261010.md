## 人工核算的实际口径

`cost_cents` 是独立可空整数分结果，代码没有规定其成本构成。`profit_cents` 同样人工录入，当前没有销售利润自动计算公式。`gift_cost_cents` 与原表“精品成本（赠送）”校验并镜像，利润与所选表的最终利润列校验并镜像。报表取审批通过的值，不重复扣减；销售业绩按实际到账日期统计。

审批额度使用销售经理明确核对的最低成交限价、赠送上限、本单赠送金额及依据；赠送金额属于销售口径，不能拿批准合同后录入的内部赠品成本代替。具体政策额度须由业务负责人核对，不在代码中猜填。
