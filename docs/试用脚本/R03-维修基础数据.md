# R03 基础数据模块 · 维修基础数据 —— 维修字典、车间班组与作业项目

**状态**：脚本已就绪，可以直接照做

## 本轮虚拟需求

维修要开单前，先把维修字典补一条、建机电组 XC-TEAM-A、再建两个作业项目（换机油、换刹车片），让接待开单时能直接选到项目和班组。

每步先核对右上角的账号、岗位和当前门店。手动 / 搜索 / 助手三种通道任选，可以混用，但同一件事不要重复提交。

- **应看到**：维修字典出现该条，且没有串到公共字典。

## 分支与找坑（可选，每轮至少挑一条）

| 类型 | 怎么做 | 应该看到 |
|---|---|---|
| duplicate | 再用编码 XC-JOB-01 建一个作业项目。 | 被拒绝或提示编码已存在。 |
| refusal | 用库管账号（xc-stock）打开作业项目维护页。 | 看不到或不能新增，提示说明由服务顾问/店长维护。 |
| stale | 两个标签页同时编辑同一作业项目的收费，先后保存。 | 后保存的一方提示资料已变化，要求刷新后核对。 |
| edge | 班组负责人留空保存。 | 允许保存（非必填）或明确提示必填，提示文字能看懂。 |

## 新用户观察点

- “车间班组”和“作业项目”两个名字，你能分清哪个是排班用的、哪个是报价用的吗？
- 作业项目的“计费单位（按次/按小时）”在页面上解释清楚了吗？
- 参考工时、收费、质保天数这些字段，哪些必填、哪些可留空？
- 编辑后有没有历史版本提示（为什么旧报价还按老价格）？
- 停用被业务引用的项目时，提示有没有告诉你去哪里处理？

- 作业项目 XC-JOB-01 换机油、XC-JOB-02 换刹车片存在，计费单位与收费与填写一致。
