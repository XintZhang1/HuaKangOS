# R02 基础数据模块 · 公共基础数据 —— 备齐公共资料：公共字典、供应商与保险公司

**状态**：脚本已就绪，可以直接照做

## 本轮虚拟需求

门店开张前把公共资料补齐：在公共字典里加一条分类，登记两家供应商（整车 星驰汽贸、物资 常青配件）和一家保险公司（华安联合财险），后面采购、保险和理赔才有资料可选。

**前置不足时**：岗位不同时先用管理员建；已有同名供应商或保险公司时先搜索再决定，不要重复新建。

## 操作步骤

每步先核对右上角的账号、岗位和当前门店。手动 / 搜索 / 助手三种通道任选，可以混用，但同一件事不要重复提交。

### R02-01

- **谁**：管理员（admin）
- **手动**：页顶搜索框（Ctrl+K）
- **搜索**：搜索框输入“公共字典”
- **做什么**：搜索“公共字典”，从结果进入“维护公共、维修、整车等分类”，在分组里点“进入字典”打开公共字典。
- **应看到**：打开“分类设置”，七个字典分组各有“进入字典”；公共字典页右侧有“新增条目”。
- **单号/记录**：

## 分支与找坑（可选，每轮至少挑一条）

| 类型 | 怎么做 | 应该看到 |
|---|---|---|
| duplicate | 再用编码 XC-SUP-CAR 建一家供应商。 | 被拒绝或提示编码已存在；不产生第二条同编码资料。 |
| refusal | 用销售账号（xc-sales）直接打开经营主数据。 | 看不到维护入口或不能新增，提示说明该资料由店长/管理员维护。 |
| stale | 两个标签页都打开同一供应商的“编辑”，A 改联系人保存，再在 B 直接保存。 | 后保存的一方提示资料已变化，要求刷新后再核对。 |
| edge | 另建一家临时保险公司 XC-INS-TMP / 试用临时财险（虚构），把它停用，再回到保险相关业务看它是否还能被选中；XC-INS-01 始终保持启用（R10 保险单要用它，别拿它做停用试验）。 | 停用的临时单位不再出现在可选列表，XC-INS-01 仍然可以选中；历史单据保留原依据。 |

## 新用户观察点

- “分类设置”里七个字典，你能一眼看出哪个是你要的吗？“进入字典”这个说法清楚吗？
- 新建字典条目时名称重复会被拦吗？说明写长了能不能看全？
- 经营主数据把供应商、保险公司放在一起，你找“供应商”要几步？类型切换明显吗？
- 必填项（付款天数、结算天数）有没有提前标出来？填 0 天能通过吗？
- 保存后有没有告诉你“下一步可以做什么”（去采购、去开保险单）？
- 搜索框是搜全部资料还是只搜当前类型？提示说得够不够？

## 结束核对

- 公共字典里能看到“代步车服务”，说明与填写一致。
- 供应商两家：XC-SUP-CAR 星驰汽贸、XC-SUP-PART 常青配件，付款天数分别为 0 与 30。
- 保险公司一家启用：XC-INS-01 华安联合财险（虚构），结算天数 15（临时单位 XC-INS-TMP 为停用试验，保持停用）。
- 用销售账号看不到（或不能新增）这些维护入口。
- 全过程没有出现真实单位名称、税号或许可证号。

**报表核对**：本轮没有金额业务，不核对报表数字。核对点是：这三类资料能在后续业务的“选择资料”里被选到（采购在 R16、保险单在 R10 验证）。
