# V2.6 AI助手适配四项业务（2026-10-09）

## 实现与审阅

原V2助手虽已只开放七个工具及business-records域，但报告目录约65K字符超过55K响应上限，连销售候选也丢失；form_data为字符串字典，原缺项解析不能定位其中字段。当前修复为：助手目录按原授权返回精简报告摘要，保留完整销售候选及服务类别；同一真实catalog接口增加report_key读取一份完整报表定义，默认网页目录不变，未知或不可见key统一404。保留原整包限额，不扩大模型权限。

操作目录使用四业务对应中文名称/检索词，inspect正确描述可选整型及合同25补充字段；中文字段key与实际合同表单逐项相同。forms支持typed additionalProperties，元字符串不乘100、不舍入，补填元金额沿主表单非负/两位精度和10亿元上限；其它金额仍整数分。售后六类提供中文label与原enum值。准备卡片不创建业务，只有原人工确认提交后自动建档；客户结果使用真实ID进入详情。

提示词、指引及工具说明同步直接填单、自动建档、customer_id关联查询、同名消歧及两种日期口径。旧模块工具、审批/核价/到账/打印/导出仍不开放，后台和人工确认、归属及门店守卫保持。root及两个代理交叉审阅通过；没有迁移或依赖变更。
