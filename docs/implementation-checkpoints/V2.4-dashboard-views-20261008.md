# V2.4 经营看板按用途展示（2026-10-08）

## 变更与审阅

本轮将统一条形图升级为业绩排行、月度折线和人工目标进度，主区域可切换来源明细。新增独立 recordcharts.js/css，businessrecords.js接入自动选择、展示切换、精确数字摘要；index.html同步资源版本。原业务API、迁移、权限、合同/核价/审批/财务状态及统计期间口径未改。

排行使用原精确十进制数比较，突出前三、相同数值并列，未知不排名、负值不当零。非人工月度图保留缺月/未知断点；人工记录不做跨行合计或月度合并。五类人工报表的8组目标/实际配对严格来自同一行，零/负/缺失目标不计算比例，超额完整显示，人工填报率另列原值。摘要金额用整数精度累计，仅用于原非人工业务记录的展示。视图切换在当前授权结果内完成，不重新请求或改动导出范围。

root人工审阅修复了进度标签遗漏门店和第二分类的问题；同行只读审阅未发现其他数据接线缺陷。原烟测两处SVG数量断言改为实际主图组件容器断言，业务断言未放宽。原shared Charts未改。
