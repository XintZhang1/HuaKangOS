- main/models/安全与附件/助手：新路由及模型、精确multipart入口和请求上限，三类附件联合恢复和孤儿清单；助手20项已审阅接口，其中仅4项既有填单写入，未开放审批、导入、交车、退车等写动作。

审查重点为每门店权限、价格冻结、无自批、历史版本兼容、原金额单位、原式净额不重扣和附件保留。总经理完整核价维持；集团副总经理可按原授权跨店看非敏感汇总，混合岗位汇总也不放开成本利润。销售经理仅有二手车表的窄写权限。
