## 基准与业务口径

基准提交 `436f913c8b34eb96e6257a2c7d4bc442661f958a` 经父任务与阿里云 release 清单比对，537 个清单源码文件哈希一致。发布目录不是 Git checkout，核对不覆盖额外文件。分支 `codex/customer-feedback-20261010` 直接从该提交开始。

此车销售总成本、此车销售利润均为人工核算后录入的可空结果；没有自动成本组成或销售利润公式。赠品成本和利润分别与原表对应值校验、同步显示；已批准报表直接使用录入值，不另扣赠品。显式清空保存、重开、提交及批准后仍为空，不能恢复旧值或转成零。

最低成交限价、赠送上限及本单赠送价值由经理逐单输入并记录依据，三个额度初始空白且必填；允许明确零。低于最低价或高于赠送上限才追加集团副总经理审批，等于额度不超限。政策数字需业务负责人确认，代码不猜测；销售赠送价值不等于内勤录入的赠品成本。
