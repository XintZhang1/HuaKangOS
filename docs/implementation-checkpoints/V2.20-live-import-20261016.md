## 已确认的阻断及修复

- 上传接口和选择器仅允许 XLSX，常见 CSV 编码、旧 XLS 无法进入识别。现在车辆表支持 XLS/XLSX/CSV/PDF/PNG/JPEG，赠品支持 XLS/XLSX/CSV；UTF-8、GB18030、带 BOM 的 UTF-16 可读。旧 XLS 用固定依赖 `xlrd==2.0.2` 读取缓存值，不启动 Excel、不执行宏或刷新链接。
- 普通超链接元数据被视为外部关系而拒绝整个 XLSX。现允许惰性链接及打印设置元数据，仍拒绝执行内容和危险压缩/XML；不会请求链接目标。原完整价格表添加普通超链接后实际识别成功。

- 模型对用途不明的“价格”不再猜成成本或售价，而是保留独立待定金额。核对页可明确选择批量填入成本或售价，仅补空白，已有数值、零及待核文字均不覆盖。未确认发布前不改变目录。
