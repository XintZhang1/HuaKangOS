# CP-08-v1：队列、持久事件与上下文编码审阅

本报告只记录源码实现与审阅。原定验收均未执行，所有验收 checkbox 保持未勾选；门禁及后续编码范围只在 implementation_plan.md 维护。四个功能开关保持默认关闭，没有启动 worker、业务实例或模型调用。

## 实现与审阅

- 队列保存真实用户 Message 与 Run；同请求键核对完整输入摘要，后台触发不伪造员工消息。数据库全局执行槽为 1，短事务领取、租约、心跳、fence 及来源版本共同阻止过期执行写回。SQLite 与 PostgreSQL 使用各自明确的锁路径；领取和回收要求新 Session，不持有写事务等待模型。原对话和 MCP 保留原忙标记语义。
- 稳定 runtime:RunUUID 忙标记不随重试变化；每次成果写入仍重验真实 Run、租约、fence、当前目标和权限。取消正在运行的任务先请求停止，安全边界后收尾。有限重试核对完整 manifest、WorkItem、Proposal 及确认记录，未知业务结果不自动重放。助手停止不撤销已提交业务。
- 事件同事务递增真实 event_seq，内容事件只能引用该 Run 实际关联的工具、卡和计划。生命周期事件由队列固定提交点生成，不把心跳、幂等返回或停止请求写成完成。普通事件能力绑定 principal、Session 事务和 fence；终态收尾能力仅用于最终展示。
- 展示以完整累计文本保存 display/revision，普通刷新最多每秒一次，终态立即保存。未完成凭据片段留在调用方内存，原推理不入事件。数据库补读由当前本人登录重新授权；后续 SSE 在每次缓存发送前仍须重验权限。业务原接口已成功与助手事件保存失败分别记录，不能把后者说成业务回滚。
- ContextBuilder 按固定顺序装配身份、目标、计划/卡/任务、新读取事实、来源快照和最近消息。用户 Run 锚定其真实 request_id 对应消息；后台 Run 只读取入队前的消息，不吸收后来排队的员工输入。绑定事项的卡片、明确对象选择和快照指针按实际 Plan/目标隔离；合法沿用的完整 manifest 保留全部输入行及原来源。
- 快照只追加，through_message_id 引用实际同会话消息。旧问答、候选、单位和已发送文件文本属于未核实来源；不会因此证明付款、库存、交接或签回。结构事实重新调用原授权 GET。快照去重只忽略观察时间，原对象版本变化必须追加，不能把旧证据重新标成当前事实。
- 30 条/24,000 字符只限制最近原文窗口，不能成为整个会话永久字数上限。当前实现保留完整来源摘录，无语义压缩或摘要模型；总容量只接受显式可信 provider 预算，不使用输出字节限制猜测输入容量。超限返回 needs_input，不截当前输入、完整工具 JSON 或未处理批量行。脱敏保留行数与 JSON 尾部；敏感字段隐藏值。
- 保存快照前完成全部原业务读取，短事务内重新核对来源、Session/Plan 版本与 fence，成果 flush 后再次验权再提交。更新计划快照指针后的新 Plan.version 回写模型上下文，避免下一次合法保存与自己的版本变化冲突。

作者、root 与独立代理分项审阅并修正了重复入队竞争、失效队首、取消/回收边界、事件权限、旧目标选择混入、完整批量恢复缺口、旧问答候选遗漏、整会话永久 24k 阻塞、快照证据误复用及返回旧 Plan.version 等问题。静态 AST、UTF-8、当前模块本地导入符号核对正常，无 U+FFFD。这些不是运行测试结果。

## 后续接入边界

M4.3 的 service 只增加 build_runtime_context 薄包装及 Runtime prompt 字段说明；原 _conversation 不调用它。M4.4—M4.6 仍须完成 provider、完整工具意图和模型循环，M5 再接 HTTP/SSE。不能把这些 helper 的存在说成 Runtime 已可运行。

worker 必须先回收、再用新 Session 领取；每个实际成果提交前完成全部读取，再调用 lock_for_write，最后复验授权。release 的 before_finish 只接同步、已构建的最终安全回复/展示，不允许联网或提交业务；队列追加终态事件。条件证明与完整工具链必须一并核对。Plan 完成导致本 Run 已收到停止请求时，使用控制取消收尾，不放宽为自动业务成功。

build_runtime_context 接受已领取 Run 的 principal；当前工具链由调用方提供完整、已解析和脱敏的本 Run 消息。reasoning 仅在该内存链中使用。ContextBuild 的 needs_input 不是成功，也不能成为重新准备已存在批量行的授权。
