2026-10-03。对应当前 `implementation_plan.md`，源码交付与正式发布分开记录。自动收口的本轮指纹、运行和限制以本轮检查点为准；历史成绩不继承。

## 验收准备

在独立副本准备合成客户、车辆、岗位和门店。不得覆盖原预览账号或公司数据。先备份数据库与附件，在副本完成完整迁移和恢复核对；迁移包括 h52j 和 h53k。四个新功能生产默认关闭，只在本次专用验收环境按明确配置开启。

员工分别使用当前门店的销售、接待、服务顾问、技师、库管、财务、客服和店长岗位。普通员工不得借用管理员会话。原人工业务页面和有效深链接始终可用。

## 员工实际操作

| 验收内容 | 员工操作与预期 |
|---|---|
| 查询 | 查询本店客户、原单状态和待办。结果对应真实来源，不生成写入卡；同名对象由本人选择。 |
| 准备及确认 | 准备一张客户/接待或维修卡，补充缺项，核对原单、金额、数量及当前门店。本人点原确认按钮后核原事实，刷新与历史不会重复提交。 |
| 批量 | 准备三项独立业务；逐张核对并确认。第二张规则拒绝或结果不明时停止，第三张仍待本人处理；第一张已办的业务保持。 |
| 跟进 | 本人逐事开启，先确认真实前序。退出后后台可查询/准备后继，后继仍要本人确认。暂停/恢复/结束保持真实授权与原业务；未开启不会自动续办。 |
| 未知结果 | 遇到结果待核对时用原核对入口，说明可靠成功、尚无回执、无法核对或来源变化。不得换请求号盲重放。 |
| 权限 | 同店不同岗位、换店、权限撤销和停用检查读写边界；迟到回复不泄露旧门店或旧会话资料，管理员授权页面的真实拒绝保持。 |
| 协作提醒 | 查看当前本人待办、真实分派/转交和站内提醒；已读不完成原业务，私有聊天/草稿不传给同事。 |
| 界面 | 在390/768/1440及常用手机上检查中文输入、焦点/光标、未发草稿、卡片、按钮、滚动、错误恢复和原业务导航。系统输入法候选需真人实机检查。 |
| 文件 | 本人选文件、上传预览、选内容、审阅后显式发送。解析文字不能当签字、扫描通过或业务完成。 |

六项体验评分分别记录：显示、步骤、文案、事实、恢复、可用性。各项至少3分并附实际观察。员工在固定同业务条件下记录原人工与助手操作的时间和正确结果；开发者脚本耗时不能替代原20%效率门槛。

## 原独立门槛

下列原计划条件需要各自真实证据。缺少条件时留待专用环境/人员验收，不用离线模型或SQLite替代：

- M8.3：独立PostgreSQL旧库升级、并发、原生数据库与附件联合备份/恢复。
- M8.4：HTTPS安全Cookie/Host/CSP、浏览器恢复、系统输入法和实机交互。
- M8.5/M8.6：明确live gate后的101/283真实模型、30条多轮和60条未调参保留表达；密钥、预算和报告留在仓库外。
- M8.7/M8.8：隔离Windows/Linux启停、睡眠/退出/恢复、独立worker、TLS/ClamAV及配置故障。
- M8.9：实际员工参与、正确性和效率记录。
- M8.10：全部原强制门槛成立后，审阅候选和回退清单；生产部署另需明确授权。

## 验收记录与回退

每次保留源码/脚本/依赖指纹、环境、岗位、门店、原对象、动作、预期/实际结果、截图或日志、失败及复验；资料全在仓库外，不上传客户数据。里程碑和CP只在实施计划登记；没有满足原全部条件，不改done/released。

启用前依次完成一致性备份→副本迁移→联合恢复核对→专用环境验收→获得上线授权→小范围启用。回退先关闭ASSISTANT_HOME_ENABLED、ASSISTANT_RUNTIME_ENABLED、ASSISTANT_FOLLOWUP_ENABLED、ASSISTANT_NOTIFICATIONS_ENABLED，停止对应新worker，保留新旧记录及全部迁移，不撤销原业务、不删除事件或流水。原业务继续按原入口处理有效事项。
