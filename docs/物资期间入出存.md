# 物资期间入出存

入口为物资菜单中的“期间入出存”。管理员、店长、财务、审计和库管可查当前授权门店；集团范围只读。库管只看数量，API、CSV与页面均不提供成本。

选择不晚于今天、跨度不超过一年的开始和结束日。期初取开始日前所有期初记录和库存流水之和；本期包含首末日；期末为期初加本期入库减本期出库。数量按物资及单位分别列出，金额为账面价值，不把库存出库直接解释为营业成本。采购、维修领退、调拨、精品退货和盘点只沿真实StockMove计一次；期初单独标明来源。

来源不足、日期顺序出现负库存或来源合计与当前库存不一致时，该物资显示差异且不提供推测期末。只要有一项不能核对，价值合计图停止显示。查询中物资版本或集合变化返回409，要求刷新。超过500项物资或25,000条关联来源明确拒绝，不截断汇总。

手机展示每项物资期初、入库、出库、期末卡片；原始流水可分页核对，CSV与报表同一集合，文本公式被转义。当前可用量和预占是另一时点视图，不冒充历史可用库存；调拨在途另列，不重复计入实物在库。尚不支持分库位历史重建。
