## 判定与处理约定

| 判定 | 可以直接改 | 必须保留 | 验证要求 |
|---|---|---|---|
| ①文案提示 | 页面文案、按钮名、错误提示、帮助文字 | 判断条件与状态机 | 改到的页面刷新后复看；`node --check` |
| ②校验默认值预填 | 前端提示与预填、必要时后端二次校验 | 岗位、门店、版本、幂等 | 加拒绝 / 重复 / 过期版本用例 |
| ③入口搜索词指引 | `docs/workflow-source/*.json`，再重建手册与搜索索引 | 已审核截图；改路由要补合成截图 | `build_workflow_guides.py --check` + 指引与搜索测试 |
| ④交互布局 | 最小前端改动 | 不隐藏关键事实、不代填业务判断 | 桌面 + 390px 窄视窗各看一遍 |
| ⑤业务规则 | 先出方案、等你确认后再改 | 原岗位、审批、库存、现金、权益、版本、幂等 | 拒绝 + 跨店 + 重复 + 过期版本 + 守恒测试 |
| ⑥缺陷 | 先复现再修 | 同上 | 复现脚本 + 修复后同脚本通过 |
| 报表口径 | 同步改代码与 `docs/指标口径.md` | 图表与表格同一人群、导出与图一致 | 图上合计 = 明细合计 |
