# 本机预览启动与首次设置

双击仓库根目录的 `start-preview.cmd`。启动器会打开本机网页；首次由使用者自行设置管理员账号与 12–128 位密码。设置成功后进入工作台。未灌入业务、员工、客户、车辆、资金、正式经营主体或期初资料，请只用虚构数据试用。

默认从 `http://127.0.0.1:8000/` 起选择可用端口，实际地址由启动器显示并打开。关闭浏览器不会关闭后台服务；再次双击会复用同目录、同源码指纹的健康进程及原端口。首次设置页面没有打开或链接失效时，再次运行启动器会生成新的 15 分钟设置链接。新链接使旧的未使用链接失效；已有账号不会因此重置。没有设置链接时，原有普通登录页和登录机制保持不变。

数据、启动状态和日志位于 `%LOCALAPPDATA%\huakangos\preview-<源码目录标识>`，与仓库 `data` 和原 `.env` 分开。启动器不读取或接管公司库，不更改旧 `start.ps1` 的启动方式，也不自动停止占用端口的其它程序。默认端口被其它服务占用时选择后续可用端口；显式指定端口被占用则报中文错误。源码已变或其它目录的进程不会被误复用，也不会改写原所属记录。启动失败显示原因和日志路径。可在 PowerShell 使用 `./start-preview.ps1 -Port 8001` 选择其它本机端口，但同一预览目录不要同时运行两个服务。

后台只绑定 `127.0.0.1`，关闭代理头信任、定时任务和外部 AI；原业务历史写开关关闭。附件采用 BLOB，仅做本地结构校验，不冒充病毒扫描。本机 HTTP 预览不代表 HTTPS 正式部署、多人正式试点或公司业务验收。

启动器用当前 Windows 用户和 SYSTEM 的目录权限保存运行文件。原始设置 token 只存在启动器内存和浏览器 URL fragment，不写文件、标准输出或服务日志；服务只读取摘要和到期时间。网页立即移除 fragment，不使用浏览器持久存储。管理员密码只经同源本机 POST 传入，数据库保存 Argon2 摘要，不生成预置密码。

首次设置必须同时满足：明确本地预览标记、实际 socket 对端为本机、预览目录及数据库实例匹配、有效的一次性设置 token、全库零用户和零门店。服务先取得数据库写锁，在一次事务内复核条件并创建门店、管理员及门店访问关系；并发请求只能一个成功。成功后保留已设置标记，重复请求不能重置账号。非本地、正式环境、伪造标记、过期链接、跨站来源、旧库和已有账号均拒绝。

本域没有新表或迁移，使用既有 `AppMetadata` 保存独立预览实例/完成标记。停止预览应由操作者核对 `process.json` 中的 PID、命令行及端口后结束本预览进程；不要按端口号批量杀进程，也不要删除运行中的数据库。

验证入口：`python -m pytest -q tests/test_local_preview.py` 和 `python tests/browser_local_preview.py`。浏览器脚本使用另建的仓库外合成目录与临时端口，完成后停止自己启动的进程，保留可复核证据；不会设置用户实际预览的管理员密码。

已有虚拟环境也会检查 Python 版本、应用依赖版本及导入可用性；依赖安装中断后再次启动会重新检查并补装。源码目录改变会使用不同默认预览目录，旧预览数据不会自动搬迁。运行中源码变更时须先核对并关闭原预览，再启动当前代码。

首次建库中断与依赖安装中断分别处理。依赖不完整时可直接重试，启动器重新检查并补装；如果首次迁移留下无完整预览标记的数据库，启动器会保留残留资料并停止，显示使用新独立预览目录的具体恢复命令。按该命令启动新的空预览即可，不删除、不接管原数据库。已有正常设置的预览不受此恢复方式影响。
