# 赠品成本额度政策

本页记录本轮技术实现与定向证据；正式里程碑及发布状态仍以根 `implementation_plan.md` 为准。

## 2026-10-12 实现边界

- 每行车型价格由上传原表的销售经理或总经理明确确认 `gift_policy` 为已核定整数分成本额度，或 `null`（未设置金额限制）；每个新批次须显式确认已核对政策。识别结果只是候选，没有明确金额时保留空值，不估算首保、NPS、项目或次数的价值。
- `h66x_vehicle_gift_policy` 仅为车型价格追加可空 JSON 列；不回填旧价格或合同。确认人和时间由服务端写入政策，批次保留原上传人和发布审计。
- 新合同冻结政策、赠品目录和成本；是否超额只比较冻结总成本和冻结额度。未知成本不能判为合规。超额或未知成本与原车价低于限价、经理人工超价取或，经理填写人工超价零不能清除自动特殊申请，仍须说明并走总经理、集团副总经理审批。
- 销售顾问只见安全通用说明、是否有限额及合规状态；经理可见政策额度，实际成本和差额仍只限原成本获权岗位。合同明细、当前目录与冻结目录使用同一权限投影。顾客合同打印未新增政策金额。
- `/api/business-records/pricing/gift-policy-check` 是登录、门店和原单重验后的只读预览，不写命令、审计或业务事实；不进入助手业务写入能力清单。门店管理员仅增加该精确只读路径，上传和发布权限不变。
- 同品牌共享当前政策；其他门店发布新批次后，已提交合同保持原政策和原赠品批次。项目、次数硬限制不在本轮范围。
