# 业务助手试用

打开 http://127.0.0.1:8000/，刷新页面，使用原账号进入“业务助手”。

1. 直接说要做什么，例如：“找到我负责的接待单，补录电话，再安排明天跟进。”助手先查找；找到多张会请你选择，不必一开始就记住单号。
2. 补充真实电话和沟通结果。助手可以先准备电话修改；缺少沟通结果时再问你。核对确认卡后点击确认，资料才会保存。
3. 查看接待单的联系电话、跟进记录和下次处理日期，确认结果。当前跟进表只记录日期；“下午”可保留在你提供的沟通内容里，没有具体时段提醒。

发送前可打开输入区的“思考”开关，默认关闭。普通填表可以先用默认模式；需要理解多个条件时可试试开启。开启后可能等待更久，效果和耗时随问题变化。

回答会逐步出现。查询资料或准备表单时显示办理状态；确认卡在准备完成后出现。界面不展示模型内部推理。

如需中止，点击“停止等待”；遇到断线或提示核对结果，先点刷新读取已有记录，再继续，避免重复发送。停止回答不会撤销已经由你确认的业务。

找不到单据时，可补充客户姓名或单号。助手仍只能使用当前门店和本人可办理的内容；不会因为打开思考而增加权限。确认卡中的资料仍需要你核对。

页顶普通搜索与AI搜索保持原来的使用方式，业务助手开关不影响搜索。

本轮已用独立合成资料分别实测关闭和开启思考的完整办理过程，未替你修改真实接待单。[验证详情](verification/assistant-thinking-20260924/测试报告.md)。
