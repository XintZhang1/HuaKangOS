# 本地资料与业务助手试用

日期：2026-09-24。先用虚构资料在试用门店操作。文件填表页面已接入；真实浏览器文件链和本轮全量结果仍以最终验收记录为准。

## 先试一条客户资料

1. 登录，确认顶部是本次要办理的门店，打开左侧 **业务助手**。
2. 点 **资料整理**，或对话框下的 **从文件填表**。
3. 点 **选择文件**，选一份自己的 `.csv`、`.tsv`、`.xlsx`、`.docx` 或 `.txt` 文件。也可以点 **选择文件夹**，明确选择一个小文件夹。多份资料请一次多选；重新选文件会替换本次预览和勾选。
4. 等待预览。在“文件”和“表格”中选要查看的内容，核对列名、姓名、电话、金额、日期和原行号。第一行作为列名，建议先把文件整理成带表头的普通表格。
5. 勾选本次需要的行。文字资料勾选 **使用这段文字**。一次先选一条；**选择本页**只勾当前页，每页最多显示 50 行。
6. 在 **要办什么事** 中填写，例如：

   > 用这条资料登记一次售前接待。已有客户先核对，不要重复建档；缺少的信息请问我。

7. 点 **核对发送内容**，检查是否只包含自己选中的资料和本次目标。关闭核对框，再点 **发送资料并填表**。
8. 助手会进入对话。它询问客户来源、车型或其他缺项时，直接在对话框回答；不确定的事实不要猜，可以回答“这项暂时没有，请告诉我下一步怎么补”。
9. 出现 **待确认** 卡片后，核对门店、办理人、客户、金额、数量等内容。正确才点 **确认办理**；有误先取消该卡片，在对话里说明修改内容。
10. 卡片显示完成后，点 **查看单据** 检查实际结果。待确认卡片、助手回复或导出的表格，都不表示业务已经办完。

如果手头没有试用文件，可以把下面三行另存为 UTF-8 的 `试用客户.csv`，这都是虚构资料：

```csv
客户姓名,联系电话,客户来源
合成试用甲,13900008601,到店咨询
合成试用乙,13900008602,电话咨询
```

只勾“合成试用甲”所在行。正常情况下，助手收到的客户资料不应包含第二位客户。重复试用时先查已有记录，不要再次新建同一个客户。

## 文件在哪一步交给助手

选择文件后，文件先交给当前 huakangos 服务做预览解析；本机试用时就在本机处理。这一步不调用 DeepSeek，也不新增客户、单据或库存。系统不会根据你输入的磁盘路径去扫描文件。

点击 **发送资料并填表** 后，选中的行或文字、必要列名和本次目标才进入 DeepSeek 对话。预览不是正式业务附件；办理需要凭据、签回或照片时，仍在对应单据中 **上传文件**。

资料页中的“清空”清除本次预览。切换门店、退出账号或刷新整个网页后，需要重新选择文件。对话记录与待确认事项在业务助手中另行查看。

## 保存一份结果

| 按钮 | 下载内容 |
|---|---|
| 导出此表 | 当前预览的整张表，保存为新的 CSV；包括没有勾选的行 |
| 导出文字 | 当前文件提取到的文字，保存为新的 TXT |
| 导出填写内容 | 一张待确认或已办理卡片的字段及内容，保存为新的 CSV |

下载不会覆盖原文件，不会把 CSV 自动写回 Excel 或 Word，也不代替确认办理。只需要部分行时，可先在原文件副本中整理好再选择。

## 遇到提示时这样继续

| 页面提示或现象 | 下一步 |
|---|---|
| 资料较多、超过发送限制 | 少勾几行，分批发送。单次对话最多 6000 字符，包含列名、文件名和系统附带说明，不只是单元格正文 |
| 文件未读取或格式不支持 | 看该文件的提示，另存为支持的普通文件后重选；不要只修改扩展名 |
| 公式为空、日期或中文需要核对 | 回原文件核对；需要公式结果时，在副本中将已核对结果粘贴为值再选择 |
| 助手尚未启用、发送按钮不可用 | 可以先预览、导出资料；联系管理员检查助手配置 |
| 对话框还有未发送内容 | 回“对话”先发送或清空原草稿，再发送文件资料 |
| 操作未完成、连接中断、待核对结果 | 点 **刷新对话**，再打开原单核对。不要另开重复申请；“停止等待”不撤销已经提交的业务 |
| 助手理解错了，或原页面也无法办理 | 打开 **问题清单 → 记录问题**，写明想办什么、卡在哪一步、提示原文和单号；必要时导出问题清单反馈 |

## 当前支持范围

- 每次最多 **20 个文件**，单个 **5 MB**，合计 **20 MB**；大文件或大文件夹请分批。单文件表格累计最多 1000 条数据、50 列，单元格最多 2000 字符。
- 支持普通 CSV、TSV、XLSX、DOCX 和 TXT。旧版 XLS、DOC、PDF、图片文字识别、扫描件、宏、加密文档及复杂嵌套或合并 Word 表格不支持。Excel 外部链接会拒绝读取。
- Excel 公式不计算，也不采用缓存结果；公式单元格留空并提示。隐藏工作表、隐藏行列和临时文件不会作为正常资料读取。Word 图片不识别。
- 助手只帮助填写、查询和办理系统已经提供的业务表单。它不运行文件里的命令、不写程序代码，也不改变员工原有的办理范围。需要主管批准、实际收付款、实物交接和签回的步骤仍分别办理。
