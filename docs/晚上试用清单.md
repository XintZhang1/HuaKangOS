# huakangos 本轮试用清单

使用你已经设置的管理员账号。地址以启动器显示为准；本次已启动在 http://127.0.0.1:8000/。服务停了就双击候选目录的 `start-preview.cmd`，已有账号和资料会保留。此处是独立预览，请使用虚构客户、车辆和凭据。

1. **打开与登录**：退出后重新登录，再次双击启动器，确认仍是原账号、原门店资料；电脑和手机窄屏查看是否有遮挡或难以理解的文字。当前只监听这台电脑，手机网页布局已按390px验证，实体手机跨设备访问另需部署配置。
2. **日常入口**：查看“我的工作”、客户服务、库存和字典，确认入口名称与公司的日常叫法是否一致。预览是空库，零条待办不是系统故障，不会自动灌入演示业务。
3. **问卷**：用虚构问卷版本和回答，对照一张单题图、展开的明细与“导出同源表”；整表导出应包含所有当前获权题目。题目内容和必答规则是否适合员工，由公司确认。
4. **岗位与跨店**：建立虚构员工后用员工账号试用；原店提出逐件档案授权，由另一有权人员批准，接收员工仅应看到获批内容。撤销后再读取应被拒绝。跨店授权不提供原业务办理权。
5. **反馈**：记录使用岗位、门店、从哪个入口开始、点击步骤、预期结果及实际结果。有提示时保留提示文字；截图请遮掉真实客户资料、密码和凭据。
