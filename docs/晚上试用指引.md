# huakangos 晚上试用指引

本机预览已更新并核对原账号和资料。打开 http://127.0.0.1:8000/ ，继续使用你已设置的管理员账号，无需重新注册。之后双击本候选目录的 start-preview.cmd 即可再打开。今晚先在本机体验，不需要先配置正式服务器。

用虚构客户、车辆和凭据办理试用单，先不录入公司正式账。自动模拟使用独立资料库；它的通过结果与公司实际验收分开记录。

## 今晚先试这几步

1. **看工作能否接得上。** 用现有管理员登录，确认当前门店，打开“我的工作”，看看单据的当前进度、下一步和负责人是否清楚。再从你最熟悉的销售、维修或采购选一条业务。
2. **走完一单维修。** 建立虚构客户与车辆，依次报价、客户授权、领料、施工、质检、结算和交车。留意每一步是否少填重复信息、能找到原单，未授权增项或质检不合格是否有清楚的提示。
3. **试一项会员业务。** 选择会员价、维修套餐或固定面额电子券中的一项：先按规则办理，再在对应业务中使用，核对本次金额、剩余次数或张数。套餐已付项目应保持原购买约定，额外自费项目单独核价。
4. **从原单退一次，再核对账。** 选择符合条件的部分退料或退款，查看原库存、原账户、剩余权益和待办；到财务报表查看同一笔收支及明细导出。已收款记录应保留，退款另有记录，不能把一次收款重复计算。

需要独立审批或其他岗位接手时，再在“员工账号”配置本次所需的试用账号，按岗位切换；管理员也不能自己申请、自己批准。缺库存、规则或凭据时，依页面提示补虚构资料即可，不必今晚补齐全公司的设置。也可先记录卡住的位置反馈。

## 反馈只需一小段

“门店／岗位：……；单号：……；我点了……；我原本希望……；实际出现……”再附一张页面截图即可。金额、数量、提示时间有疑问时，把预期值一起写上；不需要查技术日志，也不要发送密码。遇到操作冲突，先刷新核对是否已成功，再决定下一步。

公司需确认的四类规则，以及正式模板、期初和部署环境等后续验收，见[剩余验收与公司规则](剩余验收与公司规则.md)。这些事项按阶段安排，不要求今晚试用前全部完成。
