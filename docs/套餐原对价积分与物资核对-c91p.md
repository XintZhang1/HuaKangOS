# 套餐原对价、消费积分与物资报表核对

本记录限于 `c91p` 混合维修套餐的积分和物资报表适配。原套餐领域、报价、库存、售后和收退款规则由相应领域管理；本适配不增加现金流水，不更改旧集团权益的消费积分定义。

## 消费积分

客户首次授权时冻结的原会员积分规则仍是唯一依据。只有实际交车后，本店 `repair_package_payment_links` 的已核销及原冲正计入本次积分；购买付款、维修占额、已批未用退款均不产生消费积分。

设当前客户承担净额为 A，原客户现金净额、集团本金及预收抵扣之和为 K；本单已实际核销、扣除原退的套餐面值为 C、原购买对价为 P。新套餐本单的可积分消费为：

`max(0, min(A - C + P, K + P))`

两个上限同时沿原 C/P 调整。原批次按独立整数区间分摊，区间可能 C=0、P=1；此时真实使用一分不能被面值上限吞掉。没有客户承担行且只存在零面值套餐时 A=K=0，仍按 P 计算；不创建虚构客户承担或现金。没有新套餐原事实的旧业务 C=P=0，保持旧规则。

实际原配件退回并由已批售后方案生效后，以同一原区间 P 减少消费基数。未占用的原批次积分优先追回；已经兑换的部分形成原消费积分待追回，不阻止真实原款退款。恢复原权益后再次办理未用原款退款不重复减少消费积分。

独立恢复从套餐原 entry 与本地 payment link 双向核对门店、原单、动作和带符号的 C/P，再重算当前积分基数、取整、发放、追回和债额。缺失、重复或篡改投影会被拒绝；区间不套用错误的 P≤C 断言。

## 物资收入成本报表

维修仍以交车日确认原报价商品与服务金额。原套餐 C-P 单列“套餐原面值与实付对价差额（未分配商品）”，采用有符号金额，不截断负尾差，不按任意比例分到 SKU。商品、服务与未分配调整之和对应实际外部履约 P，原购买预收现金不再计收入。

后续售后按实际生效日单列原 P 收入调整。套餐配件实际收回产生的原领料成本回转，以真实库存退回日期计商品成本负数；该行收入为零，收入回转由售后调整体现。不会重写原交车期间成本，不会重复计算收入调整。

套餐停工按冻结逐组件保留数量和真实净领料列明保留配件；未做作业数量可为零。原普通项目的停工保留费仍列服务，不因为与套餐同单就编造商品销售。已领未履约成本以实际净领成本减累计履约成本核对。

报表保留既有岗位、门店和导出边界；原表、图和 CSV 使用同一数据行。指标名及公共报表入口不变。

## 验证范围

`tests/test_repair_package_points_value.py` 通过真实业务 API 建立采购、会员会期、已批套餐合同、实际购买、冻结报价、授权、领料、质检、独立承担、核销、交车、售后原配件退回及原款退款。

覆盖正常 P 加自费、未交车不发积分、部分原退、已兑换积分待追回与现金退款、真实退回期间成本、停工保留实物、C0/P1 无客户承担尾差，以及保险承担与客户原套餐权益的隔离。包含独立完整恢复和原对价投影篡改拒绝。原维修、会员、精品集团权益及原物资图表/CSV的回归另记录在验证清单中。

最终成绩和摘要以 `docs/verification/c91p-points-material.json` 为准。此处不代表整树冻结、生产环境验证或公司现场验收完成。
