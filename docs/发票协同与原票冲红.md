# huakangos 发票协同与原票冲红

本轮交付内部协同流程 v3：销售、维修、精品、加装或代办原业务 → 财务申请 → 独立主管复核 → 员工实际向外部办理 → 登记实际结果。系统不调用税务平台，不将申请、上传文件或主管批准解释为开票成功。

## 原始依据和金额

申请冻结本店原单、原单版本、金额、销售方经营主体和税号、购买方抬头、原因及计划日期。销售方须按真实经营主体填写，不能把集团产品品牌自动当作合同或开票主体。没有将业务金额转换为税率、税额或税务判断。

本店原单当前业务金额是内部申请上限。详细维修按对外承担金额、精品按当前有效收费额校验；已取消或拒绝的原单上限为零。该上限不替代财务对外部发票规则的核对。历史 v1/v2 已完成登记计入已开额度，未完成登记占用蓝票额度；历史登记没有被推断为新平台票据。

新蓝票申请、旧待办共同占额；申请冲红不会立即释放可开额度。实际红票关联一张本店实际蓝票，主体和原业务不得改换，累计已冲红与待办占额不得超过原蓝票实际金额。金额使用整数分；原申请、复核和实际结果分别保留，禁止覆盖。

## 动作、责任与异常出口

| 当前阶段 | 经办岗位及事实 | 原子影响与下一责任人 | 撤销、差异及到期处理 |
|---|---|---|---|
| 申请 | 财务或管理员；原单版本、金额、完整抬头、原因、计划日 | 新申请、原单占额、复核待办；主管接手 | 未办理可撤销；跨店、过额、过期版本拒绝 |
| 复核 | 另一位店长或管理员；本单复核凭据 | 冻结批准记录；财务提交待办 | 不允许申请人自批；可退回；仍未外部提交可取消 |
| 外部提交 | 当前财务接手人；实际办理流水及本单凭据 | 再核对原单上限；进入外部处理中，财务结果待办 | 不自动调用外部服务；不得按内部取消掩盖已提交事实 |
| 外部失败 | 财务；失败原因及证据 | 回到待提交；结果任务关闭、提交任务重开 | 重办再次打开结果任务，或确认外部失败后取消 |
| 外部差异 | 财务；异常原因、凭据、可选外部金额和票号 | 追加差异事实，保持待办 | 不因备注自动开票、退款或更改原单 |
| 实际结果 | 财务；实际票号、票面日期、金额及 invoice 类附件 | 保存唯一实际结果；主体税号与票号共同唯一；更新原单核对 | 已办理事实即使原单随后变化仍如实登记；与申请不一致则交主管复核 |
| 差异复核 | 另一位店长或管理员，不能是申请或结果登记人 | 保留原申请与实际结果，追加复核依据 | 已超过原单当前上限时保留原单财务冲红待办，不因复核完成而消失 |
| 原票部分或全部冲红 | 财务另建红票申请；主管复核；财务登记实际红票 | 关联原蓝票追加结果，实际红票后释放对应额度 | 未办理红票可取消；实际结果不可删除；不产生任何现金退款 |

所有写入共享本单版本、原单版本、请求幂等号和一个事务。不同请求并发争用原票冲红额度只允许可容纳者成功。重复同一请求返回原结果；过期版本或同请求号不同内容拒绝。待办逾期留在待办及超时统计，由主管明确转交，不自动判断办理成功。

后续真实精品退货、维修费用或权益变化会重新核对原业务。实际蓝减红超过当前上限时，生成 `invoice_adjust` 财务任务；其它流程完成不会关闭该差额任务。实际退款仍须通过原收款业务办理。

## 权限、报表与恢复

财务、店长、管理员及审计可按本店授权读取专用发票；销售、库管、技师不能读取其申请或凭据。审计只读；集团汇总只有汇总查询，不授予单店办理能力。服务端再次检查文件所属单、类别和可用扫描状态。

`invoices` 表及图按实际票面日期统计蓝减红，与 CSV 使用同一行集。`invoice_corrections` 是当前原业务差额，不按历史截止日重建。票据净额不等于营业收入、收款或退款。旧登记参与额度核对，但不混入新专用实际票据统计。

新月结来源定义 v2 纳入实际票据，按 `issued_on` 取期间，红票负数；未登记结果的申请不记为实际票额。旧月结保留定义 v1，可明确复开后按新定义核对。

数据库备份复核原单同店、原蓝票与抬头、独立复核、本单附件类别、实际结果对应事件、完成状态和红票额度。恢复不能只检查数据库可打开。

## 验证与范围

实现：`app/invoice_*.py`、`web/invoices.js`，追加迁移 `u521_invoice`。自动用例 `tests/test_invoices.py` 覆盖正向、拒绝、跨店、重复、过期版本、真实双会话额度竞争、来源变更、原精品退款、附件权限、恢复篡改、期间图表与 CSV；月结来源另见 `tests/test_operations_reconciliation.py`。

`tests/browser_invoices.py` 使用实际 Chrome、财务和店长各自账号及 390px 页面，走通蓝票100元、异常失败后重办、部分冲红30元、净额70元，现金保持零，零浏览器脚本错误。合成外部凭据仅用于测试，不是正式发票或公司验收。正式开票主体、公司业务签收及平台直连接口尚未验证。
