## 改动和问题原因

业务助手增加默认关闭的思考开关及真正的 HTTP SSE 流式回复；等待查询、准备表单时显示状态，正文增量显示，完成后显示正式确认卡。原非流式接口保留；搜索保持此前普通/AI分流方式，AI搜索继续关闭思考且只读目录。模型仅能查询与准备表单，不能改代码或自动提交。

原对话暴露出工具及提示不足：没有先查本人接待单、没将意向阶段原follow动作映射为跟进、错误使用customer而非customers被误判为权限拒绝。现在先查本人，再按需查当前可见范围；多候选/分页不自动挑选。补录电话读取原客户版本及完整字段，使用原客户修改表单；缺少真实沟通结果才追问。原来错误的资料类型返回参数错误，未经审核的路由仍拒绝。没有放宽账号、门店或岗位权限。

“明天下午”不能被虚构为时段预约：现有意向跟进只存下次日期，具体时段可保留在员工提供的沟通内容里。准备电话修改与跟进分别生成待确认表单，用户真实接待单本轮未被修改。
