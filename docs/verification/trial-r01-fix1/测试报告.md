## 权限模型（你要求的约束）

| 层 | 做法 |
|---|---|
| 服务端 | `POST /api/users/batch` 第一行就是 `admin(user)`：按**账号岗位**（`account_role`）判定，店长/销售/库管/服务/财务/审计全部 403，且在任何行被检查、任何写入发生之前拒绝 |
| 集团汇总 | 汇总视图是只读的：非 GET 请求在 `attach_scope` 被拒（403/409），批量新增也不例外 |
| 前端 | 按钮只在 `can_users`（即账号岗位为系统管理员且非汇总视图）时渲染；对话框自身再检查一次，缺权限直接报中文错误 |
| 单元不可用 | 批量新增**只能建员工账号**：`role` 为 `admin` 的行会被拒绝并提示改用“新增员工”单建，因此不会出现第二个全局管理员或绕过单建校验的路径 |
| 其它不变量 | 每行仍走 `assign_stores`（门店必须存在且启用）、写 `create_user` 审计、`must_change_password=True`；整批一个事务，任何一行不合格则一行都不写 |
