# 经营主体文档与签回

本次接入让已冻结主体的业务文档列示本单实际法定主体。`huakangos · 华慷集团` 是系统品牌，不能替代合同主体。主体资料由经营主体模块的申请和独立复核提供，本模块不作工商认证，也不推断历史业务归属。

## 冻结资料与权限

文档快照只增加四项：经营主体法定名称、主体识别号、登记地址、主体资料版本编号。前三项取自本单 `CaseEntityContext.revision_id` 对应的不可变资料版本；编号使用该原版本 ID。当前门店绑定、实体的可变版本号、账户、户名、银行渠道、联系电话及申请凭据不会进入此投影。

`snapshot(db, row, kind, *, user=...)` 和 `verify_signed(..., *, user=...)` 必须由当前获权岗位调用，重新通过本店业务可读检查和经营主体权限入口。只有财务资料授权的员工可生成相应正式单；库管、技师、前台和客服仍只能生成中性的业务记录。能够查看本单，不等于能够查看主体配置、银行渠道或其他门店业务。

已经冻结的原单不随主体新修订或门店新绑定改变。相同快照和模板版本的生成请求继续返回原文件；既有 DOCX、SHA-256、快照指纹和签回来源不会被重写。新的合规业务使用其创建时的新主体版本。

## 生成、核验和异常出口

| 环节 | 经办与前置事实 | 文件及原子影响 | 后续与异常处理 |
|---|---|---|---|
| 生成文档 | 本店获权员工；业务及对应模板存在；使用本单冻结主体 | 按既有单据生成 DOCX，记录快照、模板版本、字节摘要；经过文件存储和扫描门槛；无现金、库存或状态跳转 | 文档签回继续由原流程责任人办理；生成失败不产生业务过账 |
| 正式生成门槛 | 生产环境中的已批准车辆合同、车辆交付单、维修确认单及精品套餐报价单 | 缺少原单冻结主体时，连旧缓存正式文件的重新生成请求也拒绝 | 中文说明缺少原冻结主体；不得用当前设置或集团品牌补写历史 |
| 未批准样式 | 模板仍未批准 | 可生成明确标注“样式草稿”的样本；不能用该样本确认正式签约 | 按现有模板审批及重新生成流程办理，不自动批准 |
| 签回核验 | 原岗位有权办理原业务；签回件关联本单生成文档及实际原字节 | 仍校验文件扫描、模板批准状态和当前业务快照指纹 | 报价、配车等变化导致指纹过期时须重新生成和签回；主体新修订本身不会使旧冻结原单失效 |
| 失败、取消及超时 | 原业务及待办定义继续生效 | 本模块不新建任务、不延长期限、不撤销或删除旧文件 | 原业务取消保留文档历史；上传件不是签名真实性认证 |

主体未知且不要求追补的旧历史，快照中不增加未知标签、空主体字段或当前配置。这样旧指纹算法的输入保持不变。已批准主体政策要求冻结的新业务若丢失上下文，仍由核心主体守卫拒绝，不能降级成历史未知记录。

## 排版与验证

销售和精品专用排版把法定资料放在正文流中，长名称和地址可自然换行。通用维修/业务文档同样显示四项；较长办理内容移出禁止拆分的单元格。约定末段与签名区相连，避免长文档只剩签名落在独立空白页。表格使用明确列宽及浅灰边框，未修改任何历史文档字节。

`tests/test_business_entity_documents.py` 使用新建合成数据库的真实接口检查历史指纹、主体换版、签回关联、缓存复用、生产正式生成拒绝、银行资料最小投影以及跨店/岗位拒绝。生产环境条件在此专项中只隔离测试文档门槛，不据此宣称生产扫描或部署已验收。

`tests/qa_business_entity_documents.py` 使用文档技能提供的 Python 运行时，直接编译应用当前 `build_docx` 函数，生成销售、维修及精品各一份短单和一份长单。它不打开业务库，不复制模板实现；记录代码和文件摘要。长单使用 180 字法定名称、长地址、18 项销售约定、16 段维修内容或 24 项精品明细。使用文档技能的 `render_docx.py` 与官方校验过的本机 LibreOffice 渲染后，必须逐页检查 PNG，不能以 DOCX 可打开替代排版验收。

调用方式：使用 `load_workspace_dependencies` 返回的 Python 路径运行 `tests/qa_business_entity_documents.py --renderer <documents技能的render_docx.py路径>`；把本机 `soffice.exe` 与 Poppler 所在目录加入该进程的 PATH。默认输出到系统临时目录，也可明确指定 `--output`。合成 DOCX、PDF 和 PNG 不进入仓库；`acceptance.json` 记录每份文档的页清单及摘要。

最终验证：文档、旧流程、销售报价、精品套餐、扫描及私有附件六模块组合 84 项通过，1 项因本机 Windows 不允许创建符号链接而跳过（133.01 秒）；最后签名分页调整后，本专项 5 项再次通过（11.25 秒）。最终渲染目录 `huakangos-entity-docqa-lf7_fsaf` 在系统临时目录，销售/维修/精品短单各 1 页、长单各 3 页，共 12 页全部逐页目检。长名、长地址、表头续页、金额、约定和签名区无裁切或重叠；三个长单的末页又经另一位代理独立检查。

本次只补法定主体和签回稳定性，不代表公司已批准正式条款，也不代表所有维修、加装、保险或代办专用打印模板已覆盖。真实签名验证、工商核验和外部签章平台仍属独立范围。
