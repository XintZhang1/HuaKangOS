# UI 简化与验证记录

2026-09-27，基于 R4-B1 工作树实施。对照 main 上一个提交 `5375e7c` 的直接导航方式，保留当前业务能力。截图“修改前”为本轮修改前的 `d694a82`。

## 界面变化

- 侧栏模块直接展开操作，取消“工作台 → 全部原入口”的嵌套。
- “办一件事”改为“快捷操作”，默认最多 9 项；支持更多操作和原需求名称搜索。
- 删除模块开场提问、卡片说明和常用业务页固定介绍。完整操作说明仍可从操作指引查阅。
- 简化业务名称及按钮，减少红色按钮和重复边框。历史、流程参考和本页内容默认收起。
- 操作区、历史区使用固定 DOM 标记，不依赖中文标题。输入焦点、必填校验、放弃填写保护及助手人工确认保持。

原路由、工作流 ID、后端 API、模型提示词和权限规则未变；无数据库迁移。未启动、重置或迁移公司库及原预览库。
