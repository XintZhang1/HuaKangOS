# 试运行验收清单

先用独立演示库，再用少量经授权的去标识样例；与人工台账并行核对，不要一开始就停止原有流程。

## 第一次在你的电脑上

- 能创建自己设置密码的管理员，后续重启数据仍在；正式/演示库分开。
- 销售、库存、售后、财务各建一个账号，首次登录改密；销售看不到采购成本和整店财务。
- 录入一辆车，走完审核、订单、收款、交车；另一张订单无法同时占用该车。
- 录入维修/保单，走完审核、收款、完工；凭证或备注中含特殊字符不破坏页面。
- 核对业务日期、交车日、完工日与财务流水日期的不同；未审核金额不进入经营指标。
- 用一笔内部转账、一笔保费代收、一笔借款、一笔退款确认统计没有混入销售收入。
- 看板/CSV/日报与人工计算一致；订单金额不被当成现金收款，毛差不被当成净利润。

## 审查与 AI

- 人为制造一笔重复凭证、低毛差、超收款，能找到引用的原单和规则依据。
- 将合理重复标为正常/误报，说明留痕；模型文本不能自行改账。
- 无 Key 时规则日报仍生成；配置自己的 Key 后预览外发范围，再单次真实调用检查结果与额度。
- 手动调用失败后本地日报仍在；相同输入重复生成不会重复调用成功的 AI。
- 设置一次近期任务时间实测自动日报，确认应用必须运行；恢复默认 00:15 后核对日期是前一天。

## 正式上线之前

- 门店负责人确认角色和部门可见范围；是否必须限制销售只看自己的客户。
- 财务确认成本、含税/未税、保费、佣金、折扣、退款和交付口径；当前不支持的业务不强行录入。
- 完成正常浏览器端到端联调、Windows或目标系统测试、HTTPS/代理和 Cookie 验证。
- 用真实规模样例测响应、并发冲突和报告耗时，不根据演示库推断容量。
- 完成一次数据库备份→新环境恢复；确认备份加密、访问控制和恢复责任人。
- 核对源/目标单据数、库存 VIN、汇总金额、角色与审计日志，再切换到服务器。
- 决定客户资料保留期限、AI 外发授权、API 额度与服务器运维责任。

任何一项不符，应先修正规则或流程再扩展录入范围。日报只提示复核，不能替代会计审核、原始凭证核对或独立审计。


## 0.2 新增验收（以独立演示库完成）

建两家店，给两个员工各授权一家。用直接API而不是仅导航按钮确认另一店列表、详情、联想、导出、日报、复核都不可读；确认不同店单据号可重复，但车辆和收款不能跨店关联。确认老板汇总只含授权店，不能在汇总模式录入。

新增一个员工账号，首次改密后录入单据；修改授权门店后旧会话失效。核对旧库迁移前后条数和金额，旧数据全部归属默认门店。

自动维护先提交不含客户信息的样式意见：未勾选授权不调用模型；Docker不可用不执行宿主测试；通过后Git主分支仍不变；只有指定飞书用户可批准；拒绝后系统不变；批准后检查新SHA、备份和运行界面；重复点击不重复发布；回滚后保留发布期间新录入的一条测试流水。再模拟分支被他人更新，确认不会覆盖。

真实飞书/Docker/DeepSeek链路没有通过以上用户环境验收之前，不把自动维护当作已接通。
